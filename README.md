## Publishing a post

1. Upload the video to YouTube (Public or Unlisted)
2. Copy the video ID
3. Create `_posts/YYYY-MM-DD-short-title.md`
4. Embed video with: `{% include youtube.html id="ID" title="Description" %}`
5. Commit and push to `main`

## Tech

- GitHub Pages with Jekyll and minima theme
- Videos: YouTube embedded via youtube-nocookie.com
- Responsive 16:9 embeds
